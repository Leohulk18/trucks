# ZOINK — Built to Move El Salvador

Responsive Next.js concept site for ZOINK's U.S. trucking and construction-hauling expansion into El Salvador.

## Run locally

```bash
npm install
npm run dev
```

## Content configuration

Editable company copy, bilingual labels, fleet details, services, locations, and image directions live in `data/site.ts`.

Unknown factual details are intentionally marked as `To be confirmed` or `Planning placeholder` until ZOINK supplies verified information.
